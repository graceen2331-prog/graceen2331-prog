#### 📚 **AI PDF Translator (PDF 智能沉浸式翻译)**
* **Problem**: 传统翻译工具（如谷歌翻译）常破坏 PDF 排版，且对专业术语缺乏上下文理解。
* **Solution**: 
  1. 解析：利用 PDF 解析库精准提取文本与坐标。
  2. 翻译：接入 LLM API 进行段落级上下文翻译，保持语义连贯。
  3. 重构：基于原始坐标回填中文，**完美保留原文档格式与图表布局**。
* **Stack**: Python, PyMuPDF, OpenAI API/DeepL, Streamlit
* **Value**: 解决了外贸文档/学术论文阅读中的“格式崩溃”痛点。
